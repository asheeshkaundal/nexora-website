# Nexora Global - Color Theme

## Updated Color Palette (Based on Logo)

### Primary Colors
- **Primary Blue**: `hsl(221, 83%, 53%)` - #3b82f6
  - Main brand color, used for buttons, links, and key UI elements
  - Hover state: `hsl(221, 83%, 43%)` - Darker blue

- **Accent Cyan**: `hsl(199, 89%, 48%)` - #0ea5e9
  - Bright accent color for highlights and interactive elements

- **Secondary Blue**: `hsl(217, 91%, 60%)` - #60a5fa
  - Lighter blue for secondary actions and backgrounds

### Text Colors
- **Foreground (Dark Navy)**: `hsl(222, 47%, 11%)` - #0f172a
  - Primary text color
  
- **Muted Foreground**: `hsl(215, 16%, 47%)` - Gray text for secondary content

### Background Colors
- **Background**: `hsl(0, 0%, 100%)` - White
  - Clean, professional white background

- **Muted**: `hsl(210, 40%, 96%)` - #f1f5f9
  - Light blue-gray for card backgrounds and muted sections

- **Card**: `hsl(0, 0%, 100%)` - White cards

### Border & Input
- **Border**: `hsl(214, 32%, 91%)` - #e2e8f0
  - Subtle borders throughout the UI

- **Input**: `hsl(214, 32%, 91%)` - Matching border color for consistency

### Chart Colors
1. **Chart 1**: Primary Blue - #3b82f6
2. **Chart 2**: Accent Cyan - #0ea5e9
3. **Chart 3**: Secondary Blue - #60a5fa
4. **Chart 4**: Green - #22c55e (for success/growth)
5. **Chart 5**: Purple - #a855f7 (for variety)

## Usage Examples

### Buttons

### Links
- Default: Blue color

### Cards
- White background with subtle gray borders

### Footer
- Dark navy background (#1e293b)

## Brand Consistency
All components now use these colors through CSS variables, ensuring:
- Consistent brand identity across all pages
- Easy theme updates in the future
- Professional, modern tech company appearance
- Accessibility with proper contrast ratios
